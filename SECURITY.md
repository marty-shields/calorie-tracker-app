# Security policy

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/marty-shields/calorie-tracker-app/security/advisories/new). Do not open a public issue for it.

Include the version (Settings, or the release tag), what you did and what happened. This is a personal project: expect a reply in a few days, and a fix in the next release where one is needed.

Only the latest release is supported.

The diary entries, daily target and foods stay on the phone and in its Android backup: see [Your data](README.md#your-data) for what is stored.
Nothing you type leaves the phone. A scan sends the barcode to Open Food Facts and asks for the name, brands, pack size, serving and nutrients of that one product; no images are loaded.
